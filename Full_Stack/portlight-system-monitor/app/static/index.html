EVIDENCE CONTRACT

Observed does not mean exploitable.

Observed: Windows reports socket bindings, TCP state, owning PID, available process paths, associated services and firewall profile settings.

Inferred: service names from common port assignments and connection direction from listener matching. These can be wrong when applications use custom ports or sockets change.

Suspected: non-loopback listeners and unusual egress deserve review. No confirmed software vulnerability or malicious connection is claimed.

Unknown: internet reachability, software patch status, effective firewall rules, destination reputation and whether you still need a service.

PRIORITY RULES

Explainable review order

  • High: non-loopback endpoints on common remote-access, file-sharing, database or insecure administration ports; a disabled active firewall profile.
  • Medium: other non-loopback endpoints, public script-host egress, or a disabled inactive firewall profile.
  • Low: likely outbound TCP to a public IP on a port outside the common-egress list.
  • Info: an observation without one of those review signals. Common ports can still carry malicious traffic.

These are local heuristics, not CVSS scores or threat-intelligence verdicts. Each finding includes evidence, confidence and human review steps.
